# DER v1 - Versión inicial (borrador)

- Primer diseño del modelo, hecho en DBML (dbdiagram.io).
- Tablas sin esquemas (`Sede`, `Pais`, `Seleccion`, `Jugador`, `Partido`, `Gol`, etc.).
- Valores cerrados (posición, pierna hábil, rol técnico, rol arbitral, motivo de sustitución) como enums.
- Tipos de datos poco definidos (`varchar` sin largo, `double` para altura y peso).
- Incluye el módulo de publicidad (`Anunciante`, `Campania`, `PiezaContenido`, `PiezaMercado`, `UbicacionPublicitaria`, `Tarifa`, `ExhibicionPublicitaria`).
- Comentarios con dudas abiertas (partidos futuros, tabla de motivos, unificar formación).
